These files contain sample data captured from the Icotera i4850-31 router.

i4850-31/login_page.html - the html page served when you open the touer
i4850-31/login_success.json - the response from a POST request to index.cgi seeking to log in with valid credentials
i4850-31/login_failure.json - the response from a POST request to index.cgi seeking to log in with incorrect credentials
i4850-31/connected_devices.json - the response from a POST request to index.cgi asking for the device list
